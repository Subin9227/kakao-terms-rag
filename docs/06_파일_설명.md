## 7. `ai-test-codex` 갈래 (이 대화, 채점기 역공학)

- `ai-test-codex/v2/local_eval.py`
  - **역공학한 채점기.** `keyfact_f1 = 2|A∩G|/(|A|+|G|)`, A·G는 토큰 집합(중복 무시),
    토큰은 `[0-9A-Za-z가-힣]+` 중 순수 숫자 제외. MRR·계약 검사도 포함
- `ai-test-codex/v2/goldset.json`
  - 공개 10문항의 정답 조항과 복원한 골드 키팩트. 키팩트 개수 (2,2,5,2,3,2,3,2,2,3)는
    다른 팀의 `keyfact_recall` 분모에서 역산한 값이다
- `ai-test-codex/v2/fit_goldset.py` — 골드 키팩트 복원기. 60개 관측 MAE 0.0208
- `ai-test-codex/v2/verify_scorer.py` — 6팀 실제 점수 재현 검증
- `ai-test-codex/v2/diagnose.py` — 답변 파일 하나를 문항별로 "빠진 낱말 / 남는 낱말"로 분해
- `ai-test-codex/v2/build_terms.py` — PDF 줄바꿈이 어절 중간을 끊은 것을 사전으로 복원
- `ai-test-codex/v2/terms.json` — 정제된 72개 조항 48,663자
- `ai-test-codex/v2/retrieval.py` — BM25(어절+음절 bigram) + 문서명 부스트
- `ai-test-codex/v2/generation.py` — 유형 분류, 프롬프트, 후처리, 추출식 답변
- `ai-test-codex/v2/valset.json` — 자체 검증 18문항 (공개 문항이 쓰지 않은 60개 조항에서 제작)
- `ai-test-codex/v2/test_offline.py` — GPU 없이 28문항 × 4시나리오 + 경계 입력 7종 계약 검사
- `ai-test-codex/v2/debate/` — codex 3라운드 토론 프롬프트와 응답 전문
- `ai-test-codex/클로드_2차(1)_result_generator_9.ipynb` + 답변
  - 이 갈래가 만든 결과기. 로컬 37.33/50 (F1 0.5777). 검색은 최고지만 열거·다항에서 답이 짧아져 손해

## 9. 채점기 신뢰도 (로컬 값을 얼마나 믿을 수 있는가)

공식 채점을 받은 파일에 로컬 채점기를 그대로 돌린 결과다.

| 파일 | 공식 키팩트 F1 | 로컬 키팩트 F1 | 차이 |
|---|---|---|---|
| `eric_2_answers_public_9.json` | 0.7537 | 0.7354 | 0.018 |
| `코덱스_하이브리드(2)_answers_public_9.json` | 0.7076 | 0.6894 | 0.018 |
| 다른 팀 6팀 평균 | — | — | MAE 0.0208 |

MRR은 6팀 + 팀9 전건에서 공식 값과 정확히 일치한다. 키팩트 F1은 일관되게 0.018 정도
낮게 나오므로 **순위 비교에는 쓸 수 있고 절대값으로는 약 +0.018 보정해서 읽어야 한다.**
